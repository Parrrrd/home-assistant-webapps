# Kinder-Finanzen

Lokales Home-Assistant-Add-on zur Verwaltung von Taschengeld, verfügbarem Geld beim Kind und Eltern-Saldo.

Version 0.7.2 entfernt im Verlauf die sichtbaren Plus-/Minuszeichen bei Buchungsbeträgen. Die Auswirkung ergibt sich über den Buchungstyp; die Buchungsmaske bleibt ohne separates Feld „Richtung“.
