# BARF-Portionsrechner

Lokales Home-Assistant-Add-on zur Berechnung von BARF-Portionen für dog_one und dog_two.

## Version 0.1.11

Reis wird nur noch als roher Reis geführt. Gekochter Reis wird beim Laden alter Daten automatisch in rohen Reis umgerechnet. Der rohe Reis ist im normalen Modus und im Urlaubsmodus direkt bearbeitbar.

## Funktionen

- Tage für dog_one und dog_two getrennt eingeben.
- Halbe Tage wie 7,5 oder 7.5 nutzen.
- Gesamtmengen je Hund berechnen.
- Tagesportion je Hund anzeigen, ohne Omega-3-Kapseln einzurechnen.
- Zutaten im normalen Modus und im Urlaubsmodus separat bearbeiten.
- Gesamtmengen für beide Hunde zusammen anzeigen.
- /health zur Versionsprüfung.
